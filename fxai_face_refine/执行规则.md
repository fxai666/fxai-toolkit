# 人脸精修 · 轻量链 —— 执行规则

节点：`凤希AI - 人脸精修 · 轻量链 V2（全脸）`（`FxAiFaceRestoreLiteV2`）

引擎：VOSR2 超分（`engines/vosr2.py`）+ buffalo_l 检测/身份（`engines/detect.py`）+ inswapper_128 换脸（`engines/swap.py`）

> ## 先看这条：换脸在这里是「把自己的清晰脸写回去」，不是换人
>
> 远景小镜头里脸只有三四十像素，超分重建不出五官 —— 五官会糊、会裂、会变形。
> 本节点的主路径是：认出画面里这个人 → 用参考图里**同一个人**的清晰脸，
> 把他的糊脸写回去，再叠回超分的高频细节。**人不变，只是变清楚。**
>
> 技术上走的是 inswapper 换脸引擎，但身份来自本人，所以不会串成别人的脸。
> **这个节点不会把人换成另一个人** —— 没有「全部换成某张参考图」这种开关。
>
> 分工：**超分负责高频纹理，换脸负责低频结构。** 两者靠 `纹理保留` 配比。

面板参数名全部是中文，本文档表格里的中文名就是节点上显示的名字。
旧的英文参数名（`crop_size` / `process_max_face` …）在脚本里直接调 `run()` 时依然可用，走 `**legacy` 兜底。

## 一、默认行为（什么都不改，拖上视频就跑）

**画面里所有模糊的小脸都超分；接了参考图时，匹配上的角色再把自己的清晰脸写回去。**

| # | 规则 | 判据 | 对应参数 |
|---|---|---|---|
| 1 | **判糊** | 脸宽 ≥ `处理脸宽上限`（默认 **96px**）→ 整张跳过，不裁不超分不贴回 | `处理脸宽上限` |
| 1b | **防闪** | 阈值附近 15% 滞回，同一张脸相邻帧保持同一判定 | 内部固定 |
| 2 | **裁切自动** | 按这张脸自己的宽度定框，`裁切×倍数 = 512` | `裁切框边长 = 0`（默认） |
| 3 | **超分补纹理** | 只超分补细节，身份不变 | 无开关 |
| 4 | **认人** | 每张脸与所有参考图比一次，取相似度最大的角色 | `参考图` / `身份相似度阈值` |
| 5 | **写回清晰脸** | 匹配上参考图、且脸宽 < `换脸脸宽上限` → 用本人的清晰脸重绘；其余只超分 | `换脸脸宽上限` / `纹理保留` |

**写回默认生效**，不需要开关：接了 `参考图` 就写，没接就只超分。
脸 < 96px 时超分重建不出五官，用本人清晰脸写回是把结构救回来的唯一办法。

## 二、什么时候要动参数

### A. 要「某个片段也修一下」

默认规则跳过清晰的脸。让某一段也修，两个办法：

1. 把那段切出来单独过一次（推荐，不影响其他镜头）
2. 临时把 `处理脸宽上限` 调高（如 128），或设 0 = 全片都修

### B. 多人画面、每人一张参考图

```
参考图 = 图片序列（多个 Load Image → Image Batch）
```

- **一张参考图 = 一个角色**。视频里每张脸跟所有参考图比一次，最像谁就归谁、就换成谁
- **参考图顺序不影响匹配结果**：每张图各自提一个身份向量，取相似度最大的那个。
  顺序只影响报告里 `参考#0 / 参考#1` 的编号；`默认人物` 按这张列表数，顺序换了它指到的人就换了
- 参考图尺寸必须一致（Image Batch 节点的限制），人脸大小不用一致
- 每个角色按自己的脸宽单独定裁切框，互不拖累
- 参考图里有多张脸时**只取面积最大的那张**（三视图 / 四视图拼图同理）。
  同一人的多个角度要用上，需拆成多张单图 —— 拆开后按多个角色处理

**每个角色每帧最多认一张脸**：同一人在一帧里出现两次（镜面反射、误检）只换一遍。
同帧两人都像同一角色时，只有更像的那个换。

### C. 判定线：`身份相似度阈值`（默认 **0.10**）

**它不决定修不修** —— 修不修只看 `处理脸宽上限`。它决定「这张脸算不算参考图里那个人」，
也就是走不走写回。

```
sim ≥ 0.10  →  认成这个角色 → 写回清晰脸
sim <  0.10  →  认不出 → 只超分
```

调法：

- 漏写回（该修的没修）→ 往下调 **0.06 / 0.04**
- 认错人（路人被写成参考图里的人）→ 往上调 **0.20 / 0.30**
- 认不出也想写回 → 填 `默认人物`（见 C-1 节），整帧只有一张脸时生效

**小脸远景素材的相似度本来就很低**：

| 脸宽区间 | 相似度范围（同人） |
|---|---|
| 35~43px | 0.014 ~ 0.196，中位 0.122 |
| 60~90px | 0.60 ~ 0.95 |

所以默认取 0.10 —— 覆盖 35~43px 这一档。判定线调高只会「全都不写回」，
不会「什么都不做」，超分不受这条线影响。

### C-1. 认不出时怎么办：`默认人物`（默认 **1**）

> **定位：单人出镜专用。** 多人同框一律不写回 —— 认不出谁是谁的时候贴上去就是贴错人。
> 多人镜头要修，靠 `身份相似度阈值` 往下调（0.06 / 0.04）让它自己认出来，这一项帮不上忙。

整帧**只有一张脸**、又一张都没过判定线时，把它当成 `默认人物` 指定那张参考图里的人写回。
默认 1 = 第 1 张，所以不填参数也会写回，报告里记一笔：

```
认不出写回 12 帧（整帧一张脸、没过 0.10 线，按默认人物 参考#0 写回）
```

四个条件全中才替换：

| # | 条件 |
|---|---|
| 1 | 整帧**检出的脸数 = 1**（按检测结果算，不是按客观上几个人） |
| 2 | 这张脸宽 < `处理脸宽上限`（96） |
| 3 | 这张脸没认出任何角色（最像的也 < 判定线） |
| 4 | `默认人物` 对应的参考图存在、且检出了脸 |

第 1 条按检出框算：单人但检出 2 个框（镜面反射 / 误检）不写回；两人但有一个没检出，
只剩 1 个框，会写回。宁可少兜底，不可贴错人。

**正常路径用不到这一项**：每张脸跟所有参考图比一次，最像谁就归谁，画面里出现两三个人就各归各的，
没有「主角」这个概念，也不需要指定谁。

```
1 = 当成第 1 张参考图那位（默认）
2 = 第 2 张，以此类推
0 = 不写回，认不出就只超分
```

`默认人物 = N` 指**原始参考图列表的第 N 张**，不是「第 N 张有效图」。第 1 张检不出人脸时
`默认人物 = 1` 会告警「不可用」，不会顺延到第 2 张。

| 场景 | 填什么 |
|---|---|
| 单人远景，参考图里混了别的角色，认不出时想用某一张 | 第几张 |
| 远景小脸怎么调都过不了 0.10 | 第几张 |
| 宁可只超分，也不想贴错人 | 0 |

> 这个节点**不会把人换成另一个人**。`默认人物` 只在认不出时决定「用谁的脸补上」，
> 画面里是谁还是谁 —— 不存在「把所有人都换成某一张」的用法。

### D. 写回清晰脸：默认生效，判据是 `换脸脸宽上限`

远景小脸（35~50px）超分重建不出五官，会糊、会裂、会变形。用参考图里**同一个人**
的清晰脸写回去，是唯一能把结构救回来的办法。接了 `参考图` 就走这条，不需要额外开关。

```
参考图           = 接上 → 写回生效；不接 → 只超分
默认人物         = 1    认不出时当成第 1 张参考图那位（0 = 不写回）
换脸脸宽上限     = 96   脸宽小于它才写回，大于它只超分
换脸强度         = 1.0  合成 alpha
肤色回拉         = 0.60 肤色跟着参考走，暗光镜头调到 0.8~1.0
纹理保留         = 0.90 把超分的高频叠回去。**这个值决定成片糊不糊**
```

**`纹理保留` 是清晰度的主开关**

inswapper 输出只有 128 空间的信息量，不把超分的高频叠回去，脸就发糊。
同一张脸缩到不同宽度，比「纯超分」与「写回 + 不同纹理保留」：

| 脸宽 | 纯超分 | 纹理 0.5 | 纹理 0.7 | 纹理 0.9（默认） |
|---|---|---|---|---|
| 60px | +16.2% | +7.5% | +27.9% | **+50.0%** |
| 80px | +3.3% | −12.4% | +9.5% | **+33.8%** |

纹理保留 0.5 时，写回不如纯超分（60px 只有 +7.5%，80px 直接 −12.4%）；
拉到 0.9 后全尺寸都远超纯超分。**大脸发糊的主因是高频没叠回去，不是写回本身。**

**写回的收益拐点（纹理保留 0.5 时）**

| 脸宽 | 结论 |
|---|---|
| 30~44px | 写回占优，43px 处领先最多 |
| 46px | 打平 |
| 50px 以上 | 纯超分占优，越往上差距越大 |

拐点会随 `纹理保留` 上移：0.9 时全尺寸都占优。

**身份保持**（同一张脸缩到不同宽度，与参考身份的余弦相似度）

| 脸宽 | 原始 | 纯超分 | 写回 |
|---|---|---|---|
| 30px | 0.84 | 0.79 | **0.82** |
| 43px | 0.94 | 0.93 | **0.95** |
| 60px | 0.98 | 0.97 | 0.96 |

脸越小，纯超分掉身份越多（30px 掉 0.05），写回掉得少 —— 这就是「不裂变」的量化表现。

`换脸脸宽上限 > 处理脸宽上限` 时自动夹紧到处理上限并告警 —— 超过处理上限的脸不进入管线。

**写回的是本人，不是别人**

```
参考图   = 视频里认哪个人（决定写回谁的脸）
默认人物 = 认不出时当成哪个人（默认第 1 张，只在单人帧生效）
```

两者都不改变画面里是谁：认得出就写回本人的清晰脸，认不出就按 `默认人物` 补一张，
不想补就填 0 只超分。**没有「把所有人换成某一张」这种用法。**

**处理顺序**

```
原帧 → 裁切 → VOSR2 超分到 512 → 缩回裁切尺寸 → 椭圆羽化贴回
                                                    ↓
                    inswapper 128 换脸 → 肤色回拉 → 纹理保留 → 椭圆羽化贴回
```

换脸排在超分之后：身份由 inswapper 决定，纹理由 VOSR2 决定，`纹理保留` 把高频叠回，两者不互相覆盖。

**需要模型**：`models/insightface/models/inswapper_128.onnx`（554MB）。
首次加载解析一次 ONNX 生成 `inswapper_emap.npy` 缓存，之后直接复用。

### F. 脸宽卡在阈值附近会闪帧（滞回）

检测框每帧有几个像素的抖动。一张真实 96px 的脸，检测出来可能一帧 94、一帧 98，
裸判断就是「修、不修、修、不修」，成片上看脸在闪。

V2 用**上一帧同一张脸框的 IoU 关联**（> 0.30 才算同一张脸）做 15% 滞回：

| 上一帧状态 | 这一帧怎么判 |
|---|---|
| 在修 | 胖到 `96 × 1.15 = 110px` 才停 |
| 在跳 | 瘦到 `96 × 0.85 = 82px` 才开修 |
| 新出现 / 刚跳回画面 | 裸判断（< 96 就修） |

处理报告里给出 `滞回保持 N 张`，即被滞回留住、没跟着阈值抖的脸数。

代价：脸从 120px 缩到 92px 时先不修，瘦到 82px 才开始 —— 换来判定稳定。

### G. 前端怎么知道节点在干什么（执行状态广播）

节点一进入就打日志并广播，不等跑完：

```
[凤希AI] 人脸精修V2(全脸) 开始执行：325 帧 1280x768  参考图 1 张  引擎 vosr2
[凤希AI] 人脸精修 完成：84.1s
```

广播走 fxai-toolkit 通用通道（`fxai_task_store.broadcast` → WS 事件 `fxai:progress`）：

| 事件 | 时机 | 主要字段 |
|---|---|---|
| `face_refine_v2_start` | 参数解析完、加载模型之前 | `message` / `帧数` / `宽` / `高` / `参考图张数` / `处理脸宽上限` / `引擎` / `显卡编号` / `批大小` |
| `face_refine_v2_done` | 两条路径都发（含提前返回） | `message` / `耗时秒` / `摘要`（报告前 3 行）/ `报告`（全文） |

广播放在加载权重之前：加载要几秒，前端这段时间保持有输出。
广播失败只打日志，不影响出图。

## 三、参数速查（面板上的中文名，17 个）

面板按用途分四段排：**修哪些脸 → 认谁 → 换脸细节 → 性能**。

**输入（2 个）**

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `输入帧` | — | IMAGE 批，视频帧或单图 |
| `参考图` | 不接 | 认人用。1 张 = 1 个角色，N 张 = N 个角色。不接就只超分、不换脸 |

**修哪些脸（6 个）**

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `处理脸宽上限` | **96** | **唯一总闸**：小于它就修，大于就跳过。想多修调高；0 = 全修 |
| `裁切框边长` | **0（自动）** | 一般不动；手填只允许 128/256/512 |
| `超分倍数` | 4 | 由裁切自动配套 |
| `超分引擎` | 自研超分 (VOSR2) | 没装模型时改「纯插值 (Lanczos)」 |
| `遮罩比例` | 0.70 | 想盖到下巴/脸颊边缘调到 0.8 |
| `羽化半径` | 0.045 | 接缝硬就调大 |

**认谁（2 个）**

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `身份相似度阈值` | **0.10** | **认人判定线**，只决定写不写回。漏写回往下调 0.06/0.04，认错人往上调 0.20/0.30 |
| `默认人物` | **1** | **认不出时当成哪张**：整帧只有一张脸、又没过判定线才启动。0 = 不写回 |

**换脸细节（4 个）**

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `换脸脸宽上限` | **96** | **写回的分界线**：小于它才写回。121px 换脸 −27%，纯超分 +32% |
| `换脸强度` | 1.0 | 觉得不像本人往下调到 0.7 左右 |
| `肤色回拉` | 0.60 | 换完发白调到 0.8~1.0 |
| `纹理保留` | **0.90** | **清晰度主开关**：调低脸更糊但更贴参考，一般别低于 0.7 |

**性能（3 个）**

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `随机种子` | 42 | 一般不动 |
| `批大小` | 4 | 4 最快，8 反而慢 |
| `显卡编号` | 0 | 双卡分开跑（ComfyUI 在 Windows 上默认只放行 cuda:0） |

## 四、两个硬约束

**1. `裁切框边长 × 超分倍数` 恒等于 512**

VOSR2 训练分辨率是 512，latent 的 patch 是 16，512/16=32 必须是整数。
只有 128×4 / 256×2 / 512×1 三种配比命中。

| 配比（67px 脸） | 脸占 crop | 锐度增益 |
|---|---|---|
| 128 × 4 | 52% | **+38.0%** |
| 256 × 2 | 26% | +20.5% |
| 192 × 3 | 35% | **−52.3%** |
| 384 × 1 | 17% | +10.0% |

手填非 128/256/512 的值自动吸附并告警。

**2. 脸在裁切框里占比要够**

占比太低时超分引擎看到的是「远处的一张小脸」，重建不出五官。
裁切框按目标脸自己的宽度算（1.5 倍脸宽，向上取到 128/256/512），与全片最大脸无关 ——
否则别人的大脸会把小脸的框撑大，小脸在框里的占比被稀释。

## 五、性能参考

| 场景 | 速度 |
|---|---|
| 纯精修，单人小脸 | ~200ms/帧 |
| 纯精修，三角色同框 | ~700ms/帧 |
| 整片 325 帧（推拉门广告） | 86 秒 |
| 整片 175 帧（015） | 34 秒 |

`处理脸宽上限` 跳过的脸不进入推理管线，省下的时间约等于整帧成本，线性。
